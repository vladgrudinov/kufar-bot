# 🤖 Kufar PC Sniper & Negotiator (Облако 24/7 + Управление из Telegram)

Автоматический бот для мониторинга выгодных ПК на **Kufar.by**, оценки реальной рыночной стоимости железа, расчета маржи и торга с продавцами. 
Работает **24/7 в облаке (VPS)** или на ПК с **полным дистанционным управлением прямо через Telegram**.

---

## 📱 Дистанционное управление из Telegram

Вам не нужно постоянно заходить на сервер через консоль — всё управление вынесено в Telegram:

* **Кнопки быстрого меню:**
  * `📊 Статус бота` — текущее состояние, количество найденных ПК, отправленных офферов, аптайм.
  * `🔄 Переключить режим торга` — переключение на лету между **Полуавтоматом** (кнопки с выбором цены оффера) и **Полным автопилотом** (бот пишет продавцу сам).
  * `⏸ Пауза / Пуск` — мгновенная приостановка и возобновление сканирования.
  * `📸 Скриншот профиля Куфар` — бот делает актуальный скриншот страницы аккаунта в облачном браузере и присылает вам, чтобы убедиться, что вход активен.
  * `💎 Последние выгодные ПК` — вывод топ-5 самых профитных сборок за последнее время.
* **Интерактивные кнопки под каждым найденным ПК:**
  * `[🚀 Торговаться за X BYN]` — бот открывает чат Куфара, пишет продавцу и присылает вам скриншот с подтверждением!
  * `[📉 Торговаться еще дешевле]` — отправка более агрессивного оффера (-10% дополнительно).
  * `[❌ Пропустить]` — отправляет объявление в архив.
  * `[🔗 Открыть на Kufar.by]` — прямая ссылка на объявление.

## ☁️ Развертывание в облаке (на VPS 24/7)

Подойдет любой дешевый VPS сервер на Linux (Ubuntu 22.04 / 24.04 или Debian) с 1–2 CPU и 2 GB RAM (например: Hetzner, Beget, Timeweb, VDSina и др.).

### Вариант 1. Через Docker (Рекомендуемый в 1 команду)

1. Склонируйте или скопируйте папку `kufar_pc_bot` на сервер:
   ```bash
   scp -r kufar_pc_bot root@your_vps_ip:/opt/
   ```
2. Перейдите в папку и запустите Docker:
   ```bash
   cd /opt/kufar_pc_bot
   docker compose up -d --build
   ```
3. Бот сразу запустится в фоновом режиме 24/7 и пришлет вам сообщение в Telegram!

### Вариант 2. Без Docker (через systemd)

1. Установите Python и Playwright на сервере:
   ```bash
   apt update && apt install -y python3 python3-pip
   cd /opt/kufar_pc_bot
   pip3 install -r requirements.txt
   playwright install chromium --with-deps
   ```
2. Включите автозапуск службы:
   ```bash
   cp kufar_bot.service /etc/systemd/system/
   systemctl daemon-reload
   systemctl enable --now kufar_bot
   ```

## 🔑 Как авторизовать Куфар на облачном сервере

Так как на облачном сервере нет монитора, вход делается в 2 клика:

1. **Самый простой способ:**
   * Запустите на своем домашнем компьютере `1_LOGIN_KUFAR.bat`.
   * Войдите в свой аккаунт Куфара и закройте браузер.
   * В папке появится файл `auth_storage_state.json` (или папка `browser_session`).
   * **Просто отправьте файл `auth_storage_state.json` документом своему боту в чат Telegram!** 
   * Бот на сервере автоматически примет его и сохранит сессию.
2. Проверьте активность входа: нажмите кнопку `📸 Скриншот профиля Куфар` в Telegram. Бот пришлет скриншот вашего профиля с сервера!
